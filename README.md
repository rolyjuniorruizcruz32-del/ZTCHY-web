# Sistema de Autenticación

Aplicación web con Next.js, Supabase y SendGrid.

## Características

- ✅ Registro de usuarios
- ✅ Verificación de email
- ✅ Login/Logout
- ✅ Recuperación de contraseña
- ✅ Dashboard protegido

## Configuración

Este proyecto requiere las siguientes variables de entorno en Vercel:

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`
- `SENDGRID_API_KEY`
- `SENDGRID_FROM_EMAIL`
- `NEXT_PUBLIC_APP_URL`

Ver `.env.example` para más detalles.
